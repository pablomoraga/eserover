# ESEROver

Recurso (eXeLearning) del **ESEROver**, el rover de exploración del proyecto [Moon Camp](https://github.com/pablomoraga/mooncamp) del **Club Robótica Granada**: un Cutebot con placa micro:STEAMakers que el alumnado monta, programa y controla por IoT.

[![Abrir el recurso](https://img.shields.io/badge/▶_Abrir_el_recurso-2ea44f?style=for-the-badge)](https://pablomoraga.github.io/eserover/)

## Contenido
- Objetivos del proyecto
- ESEROver Cutebot: estructura, piezas STL, placa de control (micro:STEAMakers) y biblioteca
- Retos Cutebot «Destino Marte»: desplazamiento sobre planeta, parada en blanco, robot mágico, esquiva rocas, encerrado, siguelíneas y control remoto
- ESEROver IoT: MQTT, brokers disponibles, cómo crear un servidor MQTT, placa IoT, paneles y control wifi
- Actividades en el aula y evaluación del proyecto

> 🔒 **Las soluciones de los retos están protegidas con contraseña**, para que el alumnado trabaje los retos por su cuenta. Si eres docente y necesitas las contraseñas, contacta con el Club Robótica Granada.
